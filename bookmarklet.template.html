10to8 Rows bookmark

For computers where browser extensions are blocked. A bookmark (favourite) does the same job as the add-on: bookings with the same start time line up in rows, small gaps close, overlaps get an orange outline.

Add the bookmark (once, about 1 minute)

These steps are for Microsoft Edge (blue wave icon). Chrome works the same way.

  1. Show the favourites bar: press Ctrl + Shift + B.
  2. Drag this green button up onto the favourites bar:
    10to8 Rows

Dragging does not work? Add it by hand: press Ctrl + D to save this page as a favourite, call it 10to8 Rows and save. Right-click the new favourite → Edit, replace the URL with the text below and save.

Use it

  1. Open the 10to8 calendar and choose Day and Agenda.
  2. Click 10to8 Rows on the favourites bar.

It stays on while the calendar is open, including when you change the day. After reloading the page (F5) or opening the calendar again, click it again. It always loads the latest version, so there is nothing to update.

It only changes how the calendar looks in your browser. It does not change any bookings. If the browser add-on (Tampermonkey) is installed, you do not need this bookmark.
